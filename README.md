# KOJINGATE（個情門）

**改正個人情報保護法（APPI）＋ 電気通信事業法 第27条の12（外部送信規律）ブラウザ完結診断・公表テーブル自動生成ツール**

- 公開URL（GitHub Pages）: `https://pecopeko.github.io/kojingate/`
- オフライン・ゼロ外部通信（100% クライアントサイド ESM）

## 主な機能
1. **改正個人情報保護法（APPI）7視点チェック**: 事業者名称・住所・代表者氏名（第32条）、利用目的の特定（第17/21条）、安全管理措置（第23条）、第三者提供（第27条）、外国にある第三者への提供（第28条）、開示・利用停止請求窓口（第32〜39条）をローカルで即時判定します。
2. **電気通信事業法 第27条の12（外部送信規律）自動スキャン**: `<head>` のHTMLスクリプトやホスト一覧から GA4・GTM・Meta Pixel・LINE Tag・Yahoo!広告・X Ads・TikTok Pixel・Microsoft Clarity・Sentry・Stripe・reCAPTCHA・HubSpot を抽出し、未掲載の送信先を警告します。
3. **補正Markdown・公表テーブル自動生成**: 不足箇所を補うポリシー追記文と4要件（送信先・送信情報・利用目的・オプトアウト）のMarkdownテーブルをワンクリックでコピー・`.md` 保存できます。

node --test test/kojin-engine.test.mjs
